# Bingo Book unique battle assets

Repository source assets are compact transparent WebP files, imported in batches of 20. CI converts each committed WebP into an individual transparent PNG under `app/public/bingo/` for runtime use.

Batch 01: `bingo_001.webp` through `bingo_020.webp`.

The numeric asset ID is stable and is the same ID used by Bingo Book target definitions (`/bingo/bingo_###.png`).
