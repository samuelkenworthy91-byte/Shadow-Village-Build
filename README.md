# Kage Life

Build repository for **Kage Life**, the ninja-village management game formerly developed under the Shadow Village working title.

The player is the Kage and names the **village**, not a player character. Village identity is stored with each save and is used throughout mission, exile, recruitment and Bingo Book messaging.

The **Bingo Book** is the current endgame direction; the previously explored war/territory endgame is not part of the canonical design.

The existing Android package identifier and legacy storage keys are intentionally retained where needed for installation/upgrade compatibility. Player-facing branding should use **Kage Life**.
